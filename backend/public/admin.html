🛡️ Backpressure & Resilience Architecture

Distributed Slot Leases

Redis atomic semaphore keys coordinate max concurrency across both container replicas. If Redis is degraded, local memory failover activates immediately.

Admission Wait Deadline

Incoming requests yield for up to 750ms for an available slot before gracefully failing with HTTP 503 instead of cascading connection timeouts.

Automatic Lease Heartbeat

Active slots maintain a 180s TTL lease renewed at 60s intervals. Severed client connections automatically drop leases upon completion.
