Install in 3 steps

  1. Download the .vsix file above.
  2. In your editor open Extensions (Ctrl+Shift+X), click ⋯ at the top, then Install from VSIX…, and choose the file.
  3. Click the VynorAI icon in the sidebar and sign in.

Or from a terminal: code --install-extension vynorai-x.y.z.vsix
