Fixed locally by `textGuard.ts` (text prefix on write) and a number-format copy in the clean apply; covered by `roadmap.test.ts` with the fake workbook. Needs a deploy and a live recheck.
2. The PivotTable listed Central, Northern and Southern twice because the data holds " Central " next to "Central". Nothing warned about it. Added `valueCheck.ts`: the pane now says which grouping column has values written in more than one way and suggests cleaning first. Needs a deploy and a live recheck.
3. Wording not read by the deployed build ("fill blank cells in Qty with 0"): fixed locally (see `docs/AI500_REPORT.md`).
